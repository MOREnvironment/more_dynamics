# Frozen reference — hydrodynamics (linear damping, cross-flow drag, lift/drag, surge damping)

**Frozen** files: a changed byte in a CSV needs a decision record; a new MSS revision that changes an output adds a file `*_mss_<revision>.csv` beside the old one. Every generator lives in this repository, finds MSS only through `MSS_DIR` (MATLAB through `MATLAB_BIN`) and writes under `OUT_DIR` (default `<tempdir>/more_mss_references/<block>/`), never into this folder (except `generate_u3_surge_floating_mss.m`, below); a re-run is checked with `cmp` against the file of the same name here.

## Layout and conventions

- 50 rows in the case files; a matrix `X` is `X_01..X_36` **row-major**. `nu_r = nu − [Vc cos(beta_c − psi), Vc sin(beta_c − psi), 0, 0, 0, 0]`, `Vc = 0.3` m/s, `beta_c = 30 deg`, frozen, not recomputed.
- Two damping sign conventions: spheroid `D` as `Dmtrx.m` (positive diagonal, **subtracted**, `−D nu_r`); catamaran `D` and `tau_damp` as `otter.m` (negative derivatives `Xu..Nr`, `tau_damp` **added**). `G` is at the CO; the tests move it to the centre of flotation with `H(−r_f)`, `r_f = [LCF 0 0]`, `LCF = −0.2` m.
- `crossFlowDrag.m` hard-codes rho = 1025, `forceLiftDrag.m` rho = 1026, `coeffLiftDrag.m` e = 0.3; the blocks take them as parameters and the MSS tests pass these values.
- Instrumented MSS functions (generators of the case files): a copy written to `tempdir` at run time that only returns the function's workspace, checked equal to the unmodified function on every case (max |diff| = 0). MSS functions take actuator commands; with zero commands their actuator `tau` is zero, so the external `tau` of `inputs.csv` is added in the model's own state equation.
- Surge files: units m, kg, kg/m³, s, m/s, kg/m (`Xuu`), kg/s (`D11`, `D_nl_11`), N (`X`), m/s² (`nu_dot_1`). The OSV law's sets 2–5 are test constructions (`M(1,1) = m + A11`).
